# ChickyJoy V14

Đọc README.md ở thư mục chứa ChickyJoy.sln để mở bản chạy sẵn, tạo QR tại bàn, cấu hình AI và xem phạm vi đã kiểm tra.

Mở solution bằng Visual Studio 2022 với .NET 8 SDK để sửa mã. Thực đơn, xốt và ưu đãi dùng chung một JSON trong wwwroot/assets/catalog/store-data.json. Đơn bàn lưu ngoài wwwroot trong App_Data; giữ dữ liệu khi nâng cấp.
